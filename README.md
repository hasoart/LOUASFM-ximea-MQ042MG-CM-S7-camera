# LOUASFM — Basler acA2500-14gm

Программа для просмотра и сохранения кадров монохромной GigE-камеры Basler
acA2500-14gm. Работает на Windows x64 и Linux. Есть отдельный демонстрационный
драйвер: можно проверять интерфейс, снимки и запись без камеры.

Исходная программа сохранена в `legacy/` и первом Git-коммите `f793a16`.
Исходная папка `Camera Program/NewTmDAQ_v2` не изменялась. В этой версии, по
согласованному объёму работ, перенесены камера и наблюдение за BeagleBone.
Сканеры параметров, измерение температуры облака, Gaussian-fit и расчёт числа
атомов пока доступны только как исходники в `legacy/`. Их старые коэффициенты
не применяются к Basler автоматически.

Откройте [краткую инструкцию в браузере](docs/START_HERE.html), если нет
просмотрщика Markdown. Подробности камеры — [CAMERA.md](docs/CAMERA.md),
связь с BeagleBone — [BEAGLEBONE.md](docs/BEAGLEBONE.md).

## Установка на Windows

Рекомендуется **Python 3.11, 64 bit**, Windows 10/11 x64. Если Python уже
установлен, проверьте `py -0p` и `py -3.11 --version`. При необходимости
установите Python 3.11 с [python.org](https://www.python.org/downloads/).

1. Установите [Basler pylon Software Suite для Windows](https://www.baslerweb.com/en/software/downloads/software-downloads/).
   Выберите поддержку **GigE Camera Support / драйверы GigE** и **pylon Viewer**.
   Python-пакет pypylon включает runtime, но полноценный установщик нужен для
   сетевых драйверов и удобной диагностики. Инструкция производителя:
   [установка pylon](https://docs.baslerweb.com/software-installation-%28windows%29).
2. В pylon Viewer найдите камеру и проверьте непрерывное изображение при
   отключённом триггере. При необходимости настройте IP камеры и сетевой карты
   ПК, как описано ниже. Затем **закройте камеру в pylon Viewer**: одновременно
   управлять ею из двух программ нельзя.
3. Распакуйте папку приложения в доступный для записи каталог. Откройте
   PowerShell в этой папке:

   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe -m louasfm_camera
   ```

Активация venv необязательна: команды явно используют его Python. Права
администратора нужны установщику сетевого драйвера, но обычно не приложению.
При следующих запусках достаточно двойного щелчка по `run_windows.bat` или:

```powershell
.\.venv\Scripts\python.exe -m louasfm_camera
```

В рабочей папке подготовлены wheels для Python 3.11 / Windows x64 в
`vendor/wheels/windows/`. Они не хранятся в Git; архив с wheels поставляется
отдельно от небольшого архива исходников. Для установки из этого каталога:

```powershell
.\.venv\Scripts\python.exe -m pip install --no-index --find-links .\vendor\wheels\windows -r requirements.txt
```

Это устанавливает Python-зависимости; pylon Software Suite и сетевой драйвер
устанавливаются отдельно.

## Проверка на Linux

В этой рабочей копии venv уже создан. Запуск без камеры:

```bash
./run_linux.sh --demo
```

На другом компьютере:

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m louasfm_camera --demo
```

Для реальной камеры уберите `--demo`. Для текущих бинарных пакетов нужен
современный Linux x64: pypylon требует glibc ≥ 2.31, PySide6 6.12 — ≥ 2.34.
На Ubuntu для Qt/xcb могут потребоваться `libxcb-cursor0`, `libxkbcommon-x11-0`
и `libegl1`; при ошибке загрузки платформенного плагина установите недостающий
пакет средствами вашей системы. Настройте GigE по рекомендациям pylon для Linux.

Демонстрация использует отдельный `state/demo.json`; реальные настройки —
`state/settings.json`. Можно выбрать свой путь:

```bash
.venv/bin/python -m louasfm_camera --config /path/to/settings.json
```

## Первое подключение камеры

1. Слева выберите **Basler / pypylon**, нажмите **Найти** и выберите камеру.
   Появятся серийный номер и текущий IP. Можно ввести IP вручную, оставив
   серийный номер пустым. Если задано и то и другое, оба должны соответствовать
   одной камере. При нескольких устройствах выберите конкретное.
2. Для начала оставьте `Mono8`, binning 1, экспозицию 1000 мкс и усиление
   **Минимум камеры**. Для ширины/высоты значение 0 означает весь сенсор.
   Нажмите **Подключить**. Программа прочитает доступные форматы и параметры;
   наведите мышь на числовое поле, чтобы увидеть диапазон из камеры.
3. Выберите режим захвата. Нажмите **Применить к камере** или **Запуск**.
   Если параметры вне диапазона, программа покажет причину в журнале. После
   неуспешной частичной настройки камера закрывается: исправьте значения и
   подключите заново. Целые размеры округляются вниз до допустимого шага;
   фактически применённые значения возвращаются в интерфейс.

IP в форме подключения — адрес **камеры**, адрес BeagleBone задаётся в другой
вкладке. Для прямого соединения, например, назначьте выделенной сетевой карте
ПК `192.168.2.1/255.255.255.0`, камере `192.168.2.10/255.255.255.0`. Это пример,
а не обязательные адреса. Интерфейс к BeagleBone может оставаться в
`192.168.1.0/24`. Избегайте одинаковых подсетей на двух независимых сетевых
картах ПК. Обычный Ethernet-порт не подаёт питание PoE.

Кнопка **Временный IP камеры (ForceIP)** работает при отключённой камере.
Укажите её MAC, свободный IP в подсети камеры, маску и при необходимости шлюз.
Применение меняет только временный адрес камеры и требует повторного поиска;
IP сетевой карты ПК программа не меняет. Для постоянной конфигурации/DHCP
используйте pylon IP Configurator. ForceIP не заменяет проверку питания,
драйвера, кабеля и доступности той же физической сети.

## Просмотр, снимки и запись

| Действие | Поведение |
| --- | --- |
| **Запуск**, непрерывный поток | Кадры приходят постоянно; автозапись зависит от флажка. |
| **Запуск**, внешний триггер | Камера вооружена и ждёт импульс на выбранном Line1/фронте. Отсутствие импульса не является ошибкой таймаута. |
| **Запуск**, программный триггер | Камера ждёт кнопки **Снять и сохранить**. |
| **Снять и сохранить**, захват остановлен | Применяются выбранные настройки, временно включается Software, делается и сохраняется один кадр; затем возвращается прежний режим. |
| **Снять и сохранить**, идёт свободный поток | Сохраняется следующий полученный кадр. |
| **Снять и сохранить**, идёт внешний захват | Сохраняется следующий кадр от физического импульса. Программа не подменяет внешний триггер программным. |
| **Сохранить последний кадр** | Повторно сохраняется последний полученный кадр без новой экспозиции. |
| **Стоп** | Останавливается получение новых кадров; принятые задания записи завершаются. |

Основные кнопки также доступны на верхней панели. Для серии выберите каталог,
TIFF или PNG, задайте префикс, включите **Сохранять каждый полученный кадр**
**до запуска**. По умолчанию автоматическая запись выключена. Внизу показаны
число полученных/сохранённых кадров и очередь диска; путь последнего снимка —
в строке состояния. После Стоп дождитесь завершения очереди, прежде чем
отключать внешний диск.

В демонстрации для проверки внешнего режима используйте **Демо: внешний
импульс**. В реальном режиме эта кнопка недоступна. Демонстрация не проверяет
электрическую схему подключения.

Рядом с каждым изображением сохраняется JSON: настройки камеры, номер и
сырой timestamp камеры, время приёма ПК в UTC и последний полученный контекст
BeagleBone. Имена уникальны, предыдущие снимки не перезаписываются. Mono8
сохраняется как uint8; Mono12/Mono12Packed — как uint16 без нормализации
яркости. **Автоконтраст, масштаб и ROI анализа не меняют записываемые пиксели.**
ROI камеры в левой форме уменьшает фактически получаемый кадр; жёлтая рамка
ROI анализа меняет только статистику и профили.

Запись и камера работают вне GUI-потока. Экран показывает последний доступный
кадр, поэтому может пропускать промежуточные обновления отображения. Дисковая
очередь ограничена восемью кадрами. При её переполнении, ошибке записи или
неполном кадре захват останавливается с явной ошибкой. Это не гарантирует
получение каждого физического импульса: камера может отвергать слишком частые
триггеры, а сеть — терять пакеты. Сопоставляйте счётчик кадров с опытом.

## BeagleBone

Откройте вкладку **Схема BeagleBone**, укажите `192.168.1.66`, **UDP 9998**, канал
триггера, например D0 или D2, и нажмите **Подключить BB**. BBMain должен
работать, а его веб-страница `http://192.168.1.66:8081` должна быть открыта хотя
бы один раз для создания приложения. Камера может работать без UDP-соединения,
а схема — отображаться без камеры. Подробности и ограничения:
[BEAGLEBONE.md](docs/BEAGLEBONE.md).

## Настройки и завершение

Настройки сохраняются после изменения списка/флажка либо Enter/выхода из
числового или текстового поля. Строка состояния показывает **Настройки
сохранены** или ошибку. Предыдущая версия — `state/settings.json.bak`.
Повреждённый JSON не заменяется настройками по умолчанию: приложение сообщит
ошибку. Восстанавливайте backup при закрытой программе. `--config` задаёт свой
путь; обычный путь определяется относительно папки программы, а не текущего
каталога терминала.

Закрытие окна / Ctrl+C останавливает камеру и дожидается принятых заданий
записи. Выключение питания ПК или принудительное завершение процесса может
прервать запись. Закрытие этого приложения не выключает BeagleBone и не
останавливает его импульсы: оно только отписывается от UDP-мониторинга.

При проблеме откройте **Журнал** и файл `state/camera.log`; для диагностики:

```powershell
.\.venv\Scripts\python.exe scripts\diagnose.py
```

Скрипт выводит версии и ищет камеры, но не открывает их и не начинает захват.
Результаты проверок и оставшиеся проверки на оборудовании —
[TESTING.md](docs/TESTING.md); структура кода — [ARCHITECTURE.md](docs/ARCHITECTURE.md).
