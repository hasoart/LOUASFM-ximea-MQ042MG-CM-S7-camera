LOUASFM · Basler acA2500-14gm

Просмотр, настройка, одиночные снимки и запись кадров с аппаратным триггером. Windows x64 и Linux; Python 3.11 рекомендуется. Старые анализаторы сохранены в legacy/ и пока не запускаются.

Windows: установить один раз

  1. Установите Python 3.11 x64 и Basler pylon Software Suite с GigE Camera Support и pylon Viewer.
  2. Проверьте камеру в pylon Viewer: питание, правильная подсеть, непрерывное изображение с отключённым триггером. Затем закройте камеру в Viewer.
  3. В PowerShell, открытом в папке программы, выполните:
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m louasfm_camera

После установки запускайте run_windows.bat. Для демонстрации: run_windows.bat --demo. Для установки из поставляемой папки wheels вместо команды pip выше:

.\.venv\Scripts\python.exe -m pip install --no-index --find-links .\vendor\wheels\windows -r requirements.txt

Wheels — Python-библиотеки; сетевой драйвер pylon устанавливается отдельно.

Linux: проверить без камеры

В подготовленной рабочей копии просто выполните:

./run_linux.sh --demo

На другом компьютере:

python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m louasfm_camera --demo

Подключение и снимок

  1. Выберите Basler / pypylon (или «Демонстрация без камеры»), нажмите «Найти», выберите камеру, затем «Подключить».
  2. Начните с Mono8, binning 1, экспозиции 1000 мкс = 1 мс, усиления «Минимум камеры». Ширина/высота 0 означают весь сенсор.
  3. Выберите каталог снимков. При остановленном захвате «Снять и сохранить» делает один программный снимок. «Сохранить последний кадр» не делает новую экспозицию.
  4. Для потока выберите «Непрерывный поток» и «Запуск». Для серии включите «Сохранять каждый полученный кадр» перед запуском.

Внешний триггер от BeagleBone

Выберите «Внешний триггер», вход Line1 и нужный фронт, включите запись и нажмите «Запуск». Камера ждёт физического импульса. В этом режиме «Снять и сохранить» ждёт следующий физический триггер и не заменяет его программным. В демонстрации импульс создаётся кнопкой «Демо: внешний импульс».

Распиновка и ток оптоизолированного входа требуют проверки по документации конкретной камеры. Локальная спецификация. У модели rolling shutter; короткая вспышка может освещать строки неравномерно.

Схема BeagleBone

BBMain должен работать, его веб-страница http://192.168.1.66:8081 должна быть открыта хотя бы раз. Во вкладке схемы задайте IP платы, UDP 9998 и канал D0…D18/S0…S7; нажмите «Подключить BB». Выбор канала только подсвечивает график, а кабель подключается отдельно.

Полная длительность цикла с пустыми стадиями и хвостом 10 мс в UDP не передаётся. Контекст BB в JSON снимка приблизительный; он не гарантирует привязку кадра к конкретному циклу.

Адреса и сохранение

IP камеры задаётся слева, IP BeagleBone — в другой вкладке. Пример для отдельной сети камеры: ПК 192.168.2.1/24, камера 192.168.2.10/24. Кнопка ForceIP назначает камере временный адрес при отключённом устройстве; настройки сетевой карты ПК меняются средствами ОС. Питание камеры: PoE либо 12 В через I/O, одновременно оба не применяются.

Файлы: исходные TIFF/PNG и JSON рядом. Контраст и жёлтая ROI анализа не меняют записываемые пиксели. Изменения настроек сохраняются по Enter/выходу из поля; смотрите статус сохранения. Реальные настройки: state/settings.json, демонстрационные: state/demo.json.

Закрытие окна останавливает камеру и дожидается очереди записи. BeagleBone продолжает работать. Ошибки — во вкладке «Журнал» и state/camera.log.
