LOUASFM · XIMEA MQ042MG-CM-S7

Копия для CMOSIS CMV4000, 2048×2048, global shutter, USB3. Версия Basler сохранена отдельно. Интерфейс, снимки, запись и схема BeagleBone доступны на Windows/Linux. Для проверки без камеры есть демонстрация.

До подключения аппаратного триггера: у S7 вход HIGH требует >4 В и >2 мА. Прямой GPIO BeagleBone 3,3 В не подходит. Нужен согласующий драйвер; 5 В на GPIO BeagleBone подавать нельзя. У стандартного S7 Binder/M5: контакт 1 — I/O GND, 3 — IN, 4 — OUT. Сверьте точную модель и рисунок в официальном PDF, стр. 48–50.

Windows: установка один раз

  1. Установите Python 3.11 x64.
  2. Установите XIMEA Windows Software Package с USB3/xiQ driver, xiAPI, xiAPI Python v3, xiCamTool и xiCOP. Оригинальный установщик также подготовлен в vendor/sdk/XIMEA_Windows_SP_Stable.exe отдельного архива SDK/wheels. Запустите его самостоятельно от администратора и при запросе перезагрузите Windows.
  3. Проверьте изображение в xiCamTool/xiCOP, затем закройте там захват.
  4. В PowerShell, открытом в папке программы, выполните:
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\configure_ximea_sdk.py --sdk-root "C:\XIMEA" --check
.\.venv\Scripts\python.exe -m louasfm_camera

Замените C:\XIMEA, если SDK установлен в другом месте. Поддерживается также путь API\Python\v3, содержащий папку ximea. Модуль и DLL производителя не меняются, путь сохраняется только для этой копии проекта. Одни Python-зависимости не устанавливают SDK и драйвер камеры.

Следующие запуски — run_windows.bat. Проверка без SDK: run_windows.bat --demo. Активация venv необязательна.

Для установки Python-пакетов из подготовленного архива без интернета распакуйте SDK/wheels поверх программы и замените обычную команду pip на:

.\.venv\Scripts\python.exe -m pip install --no-index --find-links vendor\wheels\windows -r requirements.txt

Установщик SDK всё равно запускается отдельно. Старый pylon для этой копии не нужен.

Linux: попробовать сейчас

В подготовленной рабочей копии:

./run_linux.sh --demo

На другой машине:

python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m louasfm_camera --demo

Для физической камеры установите официальный Linux x86/x86_64 SDK штатным ./install, добавьте пользователя в plugdev, заново войдите в сеанс и переподключите USB-камеру. После этого:

.venv/bin/python scripts/configure_ximea_sdk.py --sdk-root vendor/sdk/extracted/package --check
.venv/bin/python -m louasfm_camera

SDK-путь — распакованный официальный пакет, содержащий api/Python/v3/ximea. Установщик 4.34 не гарантирует наличие Python-модуля в /opt/XIMEA. На Arch GUI уже проверен, а физический USB-захват ещё предстоит проверить. Подробнее SDK_SETUP.md.

Первая проверка

  1. Слева выберите XIMEA / xiAPI (USB3), «Найти», камеру по serial, «Подключить». Для демонстрации выберите соответствующий драйвер.
  2. Начальные параметры: binning 1, ширина/высота 0, offset 0, экспозиция 1000 мкс, gain «Минимум камеры», АЦП 10 бит, Mono8. Неподдерживаемые значения вызывают ошибку; реальные диапазоны читаются из камеры.
  3. Выберите каталог снимков. «Снять и сохранить» из остановленного состояния выполняет один программный снимок и возвращает прежний режим.
  4. Проверьте Raw16. TIFF/PNG сохраняют uint16-контейнер, но у этой модели 10 бит АЦП. Контраст и жёлтая ROI не меняют записываемые значения.
  5. Для серии включите «Сохранять каждый полученный кадр» перед запуском. Начните с free run, лимита 10 FPS и короткой записи на локальный диск.
Кнопка / режимДействие
Запуск, ExternalОжидание GPI1 с выбранным фронтом. Без импульсов окно остаётся активным.

В демонстрации внешний импульс создаёт кнопка «Демо: внешний импульс». В реальном режиме это физический сигнал через проверенный согласующий драйвер. Ускорять опыт следует после проверки очереди, диска и счётчиков: 90 FPS не гарантированы для 16-битного результата.

BeagleBone

Камера подключена по USB3: её IP настраивать не требуется. IP платы задаётся отдельно: например 192.168.1.66, UDP 9998. Сначала запустите BBMain и откройте http://192.168.1.66:8081 хотя бы один раз. Затем подключите BB во вкладке схемы и выберите физически используемый D0/D2.

Канал графика только подсвечивает схему; GPI1/полярность применяются к камере. Полная длительность пустых стадий и хвост 10 мс в UDP не передаются. Контекст в JSON приблизительный: не гарантирует точное соответствие кадра циклу. Закрытие камеры не останавливает BeagleBone.

Настройки и ошибки

Проверяйте «Настройки сохранены». Файлы этой копии: state/settings.json, демо — state/demo.json, SDK-путь — state/ximea-sdk-path.txt. Старый конфиг Basler не переносите. Ошибки — в «Журнале» и state/camera.log; диагностика:

.\.venv\Scripts\python.exe scripts\diagnose.py
